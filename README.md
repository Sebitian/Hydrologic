# Hydrologic

## Project Overview
Hydrologic is a smart shower monitoring system that utilizes an ESP32 microcontroller along with a water flow sensor to measure the flow rate of water from a shower head. The measured flow rate data is then sent to an Firebase cloud server for storage and analysis. The project also includes a mobile app that allows users to view and analyze the flow rate data in a meaningful way, providing insights into water usage during showers.
